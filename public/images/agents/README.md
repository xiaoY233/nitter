# Agent icons

`claude-code.svg`, `codex.svg`, `pi.svg` and `deepseek-harness.svg` come from
[LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg`
1.102.0, MIT license): `claudecode`, `codex`, `pi` and `deepseek`.

Only `width`/`height` and the inline style were edited. The marks belong to
their owners (Anthropic, OpenAI, the pi project, DeepSeek) and are used here only
to name the agent a tab refers to. DeepSeek Harness has no mark of its own, so it
shows the DeepSeek one.
